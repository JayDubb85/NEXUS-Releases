# NEXUS Downloads

This public repository hosts official NEXUS installers, checksums, release notes, and public documentation.

NEXUS is the shared foundation for the Galaxy imaging suite. It provides the browser gateway, Suite Hub, authentication, PostgreSQL database platform, and product registration used by PULSAR, SUPERNOVA, and future Galaxy products.

## Download

Use the latest GitHub Release:

```text
https://github.com/JayDubb85/NEXUS-Releases/releases/latest
```

The Windows installer is named `NEXUS-Setup-*-x64.exe`. Each release includes SHA-256 checksums.

## Documentation

Public documentation will be available through GitHub Pages:

```text
https://jaydubb85.github.io/NEXUS-Releases/
```

## Source code

NEXUS source code is maintained in a private development repository. This public repository contains downloads, public documentation, issues, and release notes only.
