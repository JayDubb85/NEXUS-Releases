# Your Galaxy suite, connected

NEXUS is the shared foundation installed before PULSAR, SUPERNOVA, or another Galaxy product. It provides one browser entry point, central sign-in, product health information, and the shared PostgreSQL database platform.

<div class="notice">
NEXUS is under active development. Installers shown as development or pre-release builds are intended for testing and must not be treated as production releases.
</div>

## What NEXUS installs

- The NEXUS Suite Hub and administration service
- Apache HTTP Server as the browser gateway
- PostgreSQL 18 as the shared database platform
- Windows services that start automatically after reboot
